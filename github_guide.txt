Part A:

1. Download the GitHub repository entirely as zip and then extract it

Part B:

1. Go to http://snap.stanford.edu/data
2. Under web graphs you will find a link named web-Google. Tap on it.
3. After that download the web-Google.txt.gz file under file section
4. Extract the file as web-Google.txt
5. Move the web-Google.txt file to the folder you just downloaded and extracted from github

Part C: 
Checking the efficiency on web-Google.txt
